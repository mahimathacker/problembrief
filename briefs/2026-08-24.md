## Research Leads
### Dynamic Debugging for Production Issues
**Category:** Devtools
**Problem:** Debugging production issues is slow and painful. Engineers often have to redeploy code with new log statements or dig through insufficient existing logs, especially when AI agents lack necessary data.
**Who'd pay:** Backend engineers and SREs who debug production applications, especially in environments using AI agents.
**First build:** A simple agent that can be deployed alongside an application, allowing engineers to inject temporary, scoped logging commands and retrieve their output in real-time without a full redeploy.
**Confidence:** medium. Big existing observability companies like Datadog or New Relic could add dynamic logging as a feature to their platforms, making a standalone product less appealing.
**Sources:** [Hacker News](https://www.hyperprobe.co)

### LL-HLS Origin Linking Reliability
**Category:** Devtools
**Problem:** Streaming media orchestrators sometimes fail to connect new streams to their LL-HLS origins, causing critical service outages without a clear fix.
**Who'd pay:** Engineers or operations teams managing live streaming infrastructure.
**First build:** A monitoring tool that detects when an LL-HLS origin fails to link and sends an alert to the operations team.
**Confidence:** low. The problem might be a bug in a specific orchestrator that its vendor will fix, or a feature that a major streaming platform could easily add.
**Sources:** [GitHub](https://github.com/OvenMediaLabs/OvenMediaEngine/issues/2277)

### Local GitHub Actions Workflow Runner
**Category:** Devtools
**Problem:** Developers are frustrated with GitHub Actions' reliability and cannot run CI workflows locally, which forces them to commit code just to test changes.
**Who'd pay:** Developers who use GitHub Actions for their CI/CD workflows.
**First build:** A command-line interface (CLI) tool that can parse a GitHub Actions workflow file and execute its steps locally, mimicking the GitHub Actions environment.
**Confidence:** low. GitHub could add a native local runner feature to GitHub Actions, making a standalone product unnecessary.
**Sources:** [Hacker News](https://preloop.dev)
