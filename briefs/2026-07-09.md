## Research Leads

### Improving Terminal Confirmation Prompts
**Category:** Devtools  
**Problem:** Clickable Yes/No prompts in terminals often lead to accidental approvals or cancellations.  
**What's already out there:** Warp Terminal's new pricing model limits AI requests to 1,500 per month. Best practices suggest using Ok/Cancel instead of Yes/No for clarity.  
**Who'd pay:** Developers using terminal interfaces.  
**How you'd win:** A tool that allows developers to customize confirmation prompts to reduce accidental actions.  
**First build:** A simple tool that replaces Yes/No prompts with clearer options like Ok/Cancel or allows users to disable them.  
**Niche test:** Developers frustrated with terminal prompts, niche score 4/5.  
**Boring test:** This is a straightforward tool for developers, boring score 5/5.  
**Big-company risk:** Medium; Microsoft or GitHub could add similar features.  
**Confidence:** Medium; big companies could easily take this idea.  
**Sources:** [GitHub](https://github.com/anthropics/claude-code/issues/70622)
