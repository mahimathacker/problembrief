## TL;DR

The strongest idea today is **cross-framework flaky test control plane**. The pain is clear, big teams already built this inside, and some tools in this area can cost around **$5,000/month**, which shows real budget.

## Buildable Ideas

### Cross-framework flaky test control plane

**Category:** Devtools  
**Problem:** Big teams lose time when tests fail at random and no one owns the cleanup.  
**What's already out there:** TestDino, ScrollTest, CodeRaven, FlakyGuard, and Autonoma. Most prices are unclear. FlakyGuard context says tools can start around **$5,000/month**. Microsoft built an internal system for this.  
**Who'd pay:** Platform teams, developer productivity teams, and QA leads at large engineering teams.  
**How you'd win:** Sit above all test tools. Read CI reports. Do not make teams add flaky tags in code. Use CODEOWNERS and issue trackers to assign work.  
**First build:** A GitHub Actions app that reads JUnit XML, finds likely flaky tests, lets teams mark them outside code, retries known flaky tests, assigns owners, and opens tickets. Start with pytest, Jest, JUnit, and Playwright.  
**Confidence:** high — It could fail if test names and test history are too hard to match across tools and CI systems.  
**Sources:** [GitHub](https://github.com/microsoft/testfx/issues/8761)

### Safe AI Pentest Copilot for SMEs

**Category:** Security  
**Problem:** Small and mid-size teams need help finding real security bugs, but many tools are costly or too complex.  
**What's already out there:** Aikido, Penligent, TrueFoundry, Escape, StackHawk, Cymulate, Picus, UnderDefense, PentestGPT, and PentAGI. Prices are mostly unclear. The research says AI security testing tools can sell for about **$500 to $5,000/month**.  
**Who'd pay:** Security leads, engineering managers, and dev teams at small and mid-size companies.  
**How you'd win:** Be the simple safe option. Use read-only mode first. Ask before active tests. Log every action. Give clear reports developers can fix.  
**First build:** A tool that connects to GitHub and one staging app or API. It finds likely issues, asks before running risky tests, saves every command and request, and creates a plain report with proof and fix steps.  
**Confidence:** high — It could fail if buyers do not trust the tool or still need a human pentester to sign off.  
**Sources:** [Hacker News](https://www.argusred.com/cli)

### Blinded evals for coding-agent review and memory

**Category:** AI agents  
**Problem:** Teams cannot tell if a coding agent is really good, or if it is using hidden help.  
**What's already out there:** Braintrust, Arize Phoenix, Promptfoo, Galileo, Cosmos, and Microsoft Copilot Agent Evaluations CLI. Prices are unclear.  
**Who'd pay:** Engineering leaders, AI platform teams, and developer productivity teams using coding agents.  
**How you'd win:** Focus only on coding-agent proof. Use hidden tasks, blocked tools, repo snapshots, leakage checks, and clear audit logs.  
**First build:** A GitHub app and CLI that runs blinded tests on real repos. Start with hidden code review bugs, memory questions with blocked web search, and repeat tasks that test saved memory.  
**Confidence:** high — It could fail if general AI eval tools add strong coding-agent tests quickly.  
**Sources:** [GitHub](https://github.com/Zhachory1/agent-fleet/issues/1), [Hacker News](https://news.ycombinator.com/item?id=48475850)

### Privacy-first age proof API for online platforms

**Category:** Security  
**Problem:** Online platforms need legal age checks, but full KYC is costly and too invasive for many apps.  
**What's already out there:** Yoti, k-ID, Persona, Klippa, KYC-Chain, and IDScan.net. Prices are mostly unclear. The research says basic services can start around **$500/month**.  
**Who'd pay:** Social apps, gaming sites, marketplaces, dating apps, and adult content sites.  
**How you'd win:** Use a cheaper step-up flow. Do simple checks first. Use selfie or ID only when needed. Return only the age result and audit proof.  
**First build:** An API for “over 18” checks. Support reusable signed age tokens, selfie age estimate with liveness, and ID check only when needed. Add logs by law, country, and check type.  
**Confidence:** high — It could fail because buyers may trust known vendors more for legal reasons.  
**Sources:** [Hacker News](https://agewarden.ai/)

### Privilege-safe automatic time capture for law firms

**Category:** Vertical saas  
**Problem:** Lawyers forget to record billable work, so firms lose revenue.  
**What's already out there:** Actionstep, WorkTime, Bloomberg Law tools, and OneAdvanced. Prices are unclear.  
**Who'd pay:** Managing partners, finance leaders, and operations leaders at small and mid-size law firms.  
**How you'd win:** Be a private time-entry helper, not employee monitoring. No screenshots. No keystroke tracking. Make review and approval fast.  
**First build:** A daily assistant that connects to email, calls, documents, and matter work. It suggests billable entries. The lawyer approves, edits, or rejects them. Then it exports to billing software.  
**Confidence:** high — It could fail if practice management tools add better time capture inside their own products.  
**Sources:** [Web](https://www.oneadvanced.com/resources/how-legal-software-powers-growth-for-law-firms), [Web](https://gainservicing.com/legal-software-for-law-firms)
