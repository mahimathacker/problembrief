No proven buildable idea today. The best lead is a clean editor for old TikZ figures, but confidence is low because a free tool already claims to do much of this.

## Research Leads

### Clean round-trip editor for old TikZ figures

**Category:** Creator tools  
**Problem:** Researchers want LaTeX-native figures, but editing TikZ by hand is slow and easy to break.  
**What's already out there:** TikZ Editor is free. Underleaf TikZ Generator is free. draw.io pricing is unclear. Inkscape is free. Adobe Illustrator is $20.99/month. DeTikZify pricing is unclear.  
**Who'd pay:** STEM PhD students, researchers, and paper authors who already use LaTeX and TikZ.  
**How you'd win:** Focus only on editing old human-written TikZ files. Keep the code clean. Keep comments, names, styles, and spacing.  
**First build:** Build a small web editor that imports one TikZ figure, shows it visually, lets users drag labels, nodes, and arrows, then writes back clean TikZ. Test it on 20 real figures from math, CS, and physics papers.  
**Niche test:** Tiny ICP: researchers with old TikZ figures in active papers. 4/5.  
**Boring test:** This is partly boring because it is about safe file editing and keeping old code readable. But it is still a niche creator tool. 3/5.  
**Big-company risk:** Medium. Likely absorber: Overleaf or a LaTeX editor.  
**Confidence:** Low. The biggest risk is that TikZ Editor already does this well enough for free.  
**Sources:** [Hacker News](https://tikz.dev/editor/)
